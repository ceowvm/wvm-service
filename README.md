# AI Marketing — обновление сервиса

Готовая версия проекта для GitHub и Netlify с согласованными правками интерфейса и логики.

## Что изменено

- установлен присланный логотип в `public/assets/logo.png`;
- название сервиса заменено на **AI Marketing**;
- удалена нумерация `01 / 02` у типов анализа;
- поля «Ниша» оформлены в современном интерфейсе;
- в анализе конкурентов добавлен раскрывающийся список регионов;
- можно выбрать несколько регионов и задать отдельное количество компаний для каждого;
- старое общее поле «Количество компаний» удалено;
- в анализе YouTube добавлен общий раскрывающийся список языков и регионов;
- доступно 30 основных языков и 30 регионов;
- для каждого выбранного языка или региона задаётся своё количество каналов;
- раздел «Дополнительные столбцы» переименован в «Параметры поиска»;
- добавлены параметры Email и Телефон;
- обновлены серверная валидация, промты, JSON-схемы и расчёт стоимости;
- сохранены фоновый режим, повторы, статус выполнения и CSV.

## Как обновить текущий репозиторий

1. Распакуйте архив.
2. Откройте папку `ai-marketing-update`.
3. Замените содержимое текущего репозитория содержимым этой папки.
4. Не удаляйте переменную окружения `OPENAI_API_KEY` в Netlify.
5. Выполните в Netlify: **Deploys → Trigger deploy → Clear cache and deploy site**.

Старый файл `public/assets/logo.svg` больше не используется и удалён из обновления.

## Переменные Netlify

Обязательная:

```text
OPENAI_API_KEY=...
```

Необязательная:

```text
OPENAI_MODEL=gpt-5.6
```

## Ограничения

За один запуск разрешено запросить до 100 компаний или каналов суммарно. Максимум для одного выбранного языка/региона — 50.
